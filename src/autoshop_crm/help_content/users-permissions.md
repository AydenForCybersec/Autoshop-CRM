# Users and Permissions

## Add a user
1. Open **Settings**.
2. Go to **Users**.
3. Create the account and select the closest matching role.
4. Confirm the account is active.

## Tune permissions
1. Open **Permissions** tab.
2. Select the user.
3. Enable only required permissions.
4. Save and ask user to sign in again.

## Role assignment pattern
- **Owner/Admin**: full operations, user management, settings
- **Service writer/front desk**: customer, vehicle, and job intake/update
- **Mechanic/technician**: operational records needed for assigned work
- **Accounting**: billing/reporting areas only

## Safety rules
- Keep at least one additional active admin account.
- Avoid granting broad permissions "temporarily" without follow-up.
- Review access whenever employees change responsibilities.

## If this fails
- You cannot edit users: your own role may lack admin permissions.
- User still blocked after changes: ask them to sign out/sign in again.
- Unexpected access remains: verify both role defaults and per-user overrides.
