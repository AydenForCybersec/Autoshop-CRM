# Usage Guide

Use this guide for full day-to-day operation inside the web app.

## Who this is for
- Service writers
- Front desk staff
- Shop admins who also handle daily intake

## Before you start
- You can sign in successfully.
- You have customer contact info and vehicle details available.
- You know your shop's workflow status labels (for example: Open, In Progress, Completed).

## Standard process: intake to completion
1. Open **Customers**.
2. Search for the customer first to avoid duplicates.
3. If no match exists, create a new customer with complete contact details.
4. Open the customer record and add the vehicle.
5. From the vehicle page, create a new job/work order.
6. Fill in complaint, notes, and estimate details before saving.
7. Update job status as work progresses.
8. Mark the job completed only after final review.

## During the day
1. Keep records updated in real time instead of at end of day.
2. Add notes when information changes (customer call, parts status, approval updates).
3. Re-check duplicates when adding customers or vehicles with similar names/plates.
4. Use the dashboard to monitor open/completed work and totals.

## End-of-day checks
1. Review jobs still marked open and confirm status is accurate.
2. Confirm high-priority jobs have clear notes for next shift.
3. Verify newly completed work has final totals and customer-ready notes.

## Quality standards
- Every job must be linked to the correct customer and vehicle.
- Status must reflect real shop state.
- Notes should be clear enough for another team member to continue without extra context.

## If this fails
- If you get blocked by permissions, contact an admin to review your role.
- If records look duplicated, use existing records when they match.
- If totals or lists seem stale, refresh once and re-check.

## Done when
- You can run the full intake-to-completion flow without missing required fields.
- Job status and notes stay accurate throughout the workday.
