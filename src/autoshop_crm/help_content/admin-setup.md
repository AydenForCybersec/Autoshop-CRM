# Admin Setup Checklist

Use this checklist after technical deployment is already complete and the web app is reachable.

## Before starting
- Confirm you are at the correct app URL for your shop.
- Confirm no one has created the first admin account yet.

## In-app setup
1. Open `/setup-admin`.
2. Create the first admin account with a strong password.
3. Sign in and open **Settings**.
4. Complete business profile fields (name, phone, email, address).
5. Verify dashboard and customer pages load.
6. Create at least one additional admin account to avoid single-account lockout.

## Access setup
1. Create user accounts for staff who need access.
2. Assign each user an appropriate base role.
3. Review permission overrides only when role defaults are not enough.

## If this fails
- Setup page not available: ask technical staff to confirm deployment is complete.
- First admin creation fails: verify required fields and retry.
- Missing areas after login: confirm your account role has required access.
