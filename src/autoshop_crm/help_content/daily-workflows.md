# Daily Workflows

## Front desk workflow
1. Open **Customers**.
2. Search before creating a new customer.
3. Open the customer profile and verify phone/email details.
4. Add or select the correct vehicle.
5. Create the job with clear complaint and initial notes.
6. Confirm required fields are saved.

## Shop floor or advisor updates
1. Open the active job from vehicle or related lists.
2. Update status as work moves through shop stages.
3. Add notes for approvals, delays, and parts updates.
4. Keep totals/details accurate before marking complete.

## Admin review workflow
1. Open **Dashboard** for current shop snapshot.
2. Review open jobs and stale records.
3. Check role/permission gaps reported by staff.
4. Verify settings and business profile remain current.

## Common choices
- Duplicate warning appears: choose the existing record when it is a real match.
- Required field error appears: complete missing fields and submit again.
- A user cannot access a page: admins should review that user's permissions.
