# Settings and Branding

## Who this is for
- Owners and admins managing shop profile and appearance

## Business profile updates
1. Open **Settings**.
2. Go to the **Business** section.
3. Update shop name, phone, email, and address fields.
4. Save and confirm updates appear on key pages.

## Logo and visual theme
1. Open the **Theme** section in **Settings**.
2. Upload a clear logo image.
3. Apply brand color changes carefully.
4. Save, then review multiple screens for readability.

## Brand consistency checks
- Shop name spelling is consistent.
- Contact information matches official channels.
- Buttons, headings, and text keep strong contrast.

## If this fails
- Logo upload fails: use a supported image format and smaller file.
- Colors reduce readability: revert to the previous palette.
- Changes do not appear: refresh and verify the save completed.
