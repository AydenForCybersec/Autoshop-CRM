# Admin Guide: Settings and Branding

## Who this is for
Admins updating business profile and visual theme.

## Before you start
- Logo file is a supported image format.
- You know official shop contact details.

## Step-by-step
1. Open `Settings` -> `Business` tab.
2. Update shop name, phone, email, and address.
3. Upload logo if needed.
4. Open `Theme` tab.
5. Adjust colors and save.
6. Refresh key pages to verify readability.

## If this fails
- Invalid logo: use supported extension and smaller file.
- Hard-to-read colors: revert to previous palette.
- Save appears successful but unchanged: refresh and retry once.

## Done when
- Branding is consistent across pages.
- Text contrast and buttons remain readable.
