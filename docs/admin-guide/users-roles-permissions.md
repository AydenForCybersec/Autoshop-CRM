# Admin Guide: Users, Roles, and Permissions

## Who this is for
Admins managing access control.

## Before you start
- You have `manage_users` and `manage_permissions` access.
- You know each employee job function.

## Step-by-step
1. Open `Settings` and go to `Users` tab.
2. Create user with role: Admin, Owner, Mechanic, Accountant, Service Writer, or Custom.
3. Open `Permissions` tab.
4. Select the user and enable only needed permissions.
5. Save and ask user to sign out/in.

## If this fails
- Cannot edit user: verify your own admin permissions.
- User still blocked: check custom overrides and role defaults.
- Risk of lockout: keep at least one active admin account.

## Done when
- Every active user has least-privilege access.
- Role assignments match real responsibilities.
