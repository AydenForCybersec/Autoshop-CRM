# User Guide: Getting Started

## Who this is for
Shop staff and service advisors who use the CRM daily.

## Before you start
- You have a username and password from your admin.
- The server is running and you can open the app URL.

## Step-by-step
1. Open the CRM URL in your browser.
2. Sign in on the Login page.
3. From the top menu, choose `Customers`.
4. Confirm you can see customer records.
5. Open `Help` in the top menu when you need task guides.

## If this fails
- If login fails, ask an admin to verify your account is active.
- If you see a setup screen instead of login, the app is still in first-time setup.
- If the page does not load, ask your admin to check server status.

## Done when
- You can log in.
- You can open the `Customers` page.
- You know where to find `Help` in the app.
