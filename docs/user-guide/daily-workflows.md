# User Guide: Daily Workflows

## Who this is for
Shop staff creating and tracking customer work.

## Before you start
- You can sign in successfully.
- You have customer and vehicle details ready.

## Step-by-step
1. Add or find a customer in `Customers`.
2. Open the customer and add a vehicle.
3. Open the vehicle and create a work order/job.
4. Update job status as work moves from `Open` to `Completed`.
5. Check `Dashboard` for totals and recent activity.

## If this fails
- Duplicate warning: choose existing customer/vehicle or merge when prompted.
- Missing fields: fill required fields and try again.
- Permission message: ask an admin for correct role permissions.

## Done when
- Customer, vehicle, and job are linked.
- Job status reflects the real shop state.
- Dashboard totals update after your changes.
