# User Guide: Common Problems

## Who this is for
Staff who need quick fixes without technical steps.

## Before you start
- Keep your browser open to the exact screen with the issue.
- Write down the message shown on screen.

## Step-by-step
1. If you cannot log in, verify username/password and contact admin.
2. If a record is missing, search by name, phone, or vehicle details.
3. If duplicate prompt appears, choose the best matching record.
4. If you are blocked by permissions, ask admin for access update.
5. If pages are stale, refresh and retry once.

## If this fails
- Capture the exact error text and time.
- Share the steps that caused the issue.
- Escalate to admin/developer with those details.

## Done when
- You can continue your workflow.
- Any unresolved issue has reproducible notes for handoff.
